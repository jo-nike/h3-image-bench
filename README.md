# MiniMax-H3-Image Bench

A gallery of 300 graded text-to-image prompts rendered with MiniMax-H3-Image at ~16 MP on a single RTX 5080 (16 GB), stock ComfyUI workflow.

Live page: https://jo-nike.github.io/h3-image-bench/

- `full/` full-resolution WebP (quality 90), `thumb/` grid thumbnails, `data.json` prompts, checklists, render log and grades.
- Original PNGs are attached to the [`originals` release](https://github.com/jo-nike/h3-image-bench/releases/tag/originals).
- All images are AI-generated by MiniMax-H3-Image, under the [MiniMax-H3-Image Community License Agreement](https://huggingface.co/MiniMaxAI/MiniMax-H3-Image/blob/main/LICENSE).
